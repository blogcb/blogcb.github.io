【Fanly XZH V1.7】百度熊掌 ID推送及网页改造插件[WordPress插件]

Fanly XZH，是一款为了让 WordPress 站点用户快速便捷的接入改造熊掌号/熊掌 ID 搜索结果出图页面而开发的插件，利用 WordPress 熊掌 ID 页面改造插件，可以将原有 MIP 主题页面、移动端 H5 主题页面、自适应主题页面站点在无需修改任何代码的情况下实现熊掌号页面接入、结构化改造以及粉丝关注改造。

从 Fanly Submit 熊掌号数据推送插件发布以来，就广受 WordPress 站点用户的青睐和喜爱，但是该插件仅作为数据推送使用，并不能实现熊掌号页面改造，从而导致许多的小白或不懂代码的用户无法顺利完成改造接入，即使子凡曾在泪雪博客发布过WordPress 熊掌号改造教程，也未能拯救想要尝鲜熊掌号收益的朋友们，顾特此开发 Fanly XZH 熊掌号改造插件来弥补和完善这个空缺。

Fanly XZH 简介

Fanly XZH，即子凡的英文名：Fanly，加上熊掌号：XZH，的首字母拼写组合而成，实现了 WordPress 站点快速改造接入百度熊掌号，真正的让小白用户或不喜欢折腾改代码的同学们能够专心的做网站运营，而不是放在这些修修改改的技术问题上。

Fanly XZH 特色

通过插件设置页面配置好熊掌号 ID、页面类型以及需要生效的主题，即可完成所有的改造配置操作。

注意：Fanly XZH 插件并不会修改任何主题代码，更不会修改原站点任何配置信息，所以大胆的使用即可。

Fanly XZH 插件须知

本插件仅用于 WordPress 自适应、H5、MIP 站点主题的“文章”和“页面”类型的熊掌号改造，而并非实现全站的熊掌号改造，故“首页”、“分类目录”、“标签”等页面是无法实现熊掌号改造支持的。所以最终配置设置好 Fanly XZH 熊掌号插件后，使用“在线校验工具”校验时请校验具体的文章内容页面，而非首页。

同时需要明确的是，Fanly XZH 插件仅仅只是用于熊掌号页面改造，并不支持数据和内容的提交，所以需要完整的接入熊掌号还需要配合子凡提供的 Fanly Submit 熊掌号数据提交插件。
