# codexweb-v2 在线开发平台最新版
面向 开发的 Web IDE，用于编写和开发程序，全自动完成，

**前台功能**

- 用户注册、登录、修改密码，余额与 VIP 权益管理。
- AI 对话与流式输出，可选择模型、使用个人模型配置。
- AI Agent 可调用文件、终端等工具完成开发任务，并实时显示执行日志与任务状态。
- 项目文件浏览、创建、编辑、删除、上传下载，Monaco 代码编辑器与多标签编辑。
- 代码补全、选中代码的内联 AI 编辑、Diff 预览及接受/拒绝修改。
- 项目上下文收集、文件 `@` 提及、上下文压缩与会话记忆。
- 多 Agent 任务视图、任务确认流程，以及代码变更编排流水线。
- Git 状态、提交历史、差异查看、快照、分支与 Pull Request 操作。
- 终端、问题列表、调试、构建、沙盒命令执行与 CI/CD 查看。
- 代码质量评分、Bug 检测、依赖审计、安全扫描、测试覆盖率和验证结果。
- 智能重构、批量编辑、代码片段管理、技能管理、扩展管理。
- 文件变更监听、项目类型检测与代码索引。
- 工件预览、对话分支、Diff 评论、项目分享。
- 可调整 IDE 布局、深浅主题及面板显示状态。

**后台功能**

- 系统状态与运行指标查看。
- `.env` 系统配置和数据库配置管理。
- AI API 接口配置、模型获取/注册、故障切换策略。
- 用户管理：查看用户、删除用户、调整余额。
- 卡密生成、查看与删除。
- VIP 规则配置：会员期限、每日 Token 额度、新用户体验余额。
- AI 用量统计与调用记录。
- AI 模型配置维护。
- 安全策略与命中记录查看。
- 用户工作区文件浏览、下载与删除。
- CI/CD 配置查看与扩展管理。
